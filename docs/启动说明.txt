个人技能树 · 免安装版
====================

1. 请先完整解压压缩包，保留整个 SkillTree 文件夹。
   不要只把 SkillTree.exe 单独复制出来，它需要同目录的 SkillTree-app.exe、resources、DLL 和 pak 文件。

2. 双击 SkillTree.exe。
   这是启动器；真正的主程序是旁边的 SkillTree-app.exe。
   两个文件都要保留，不要改名、不要删除。

3. 启动器会先正常启动；如果当前 Windows 会话无法初始化 Chromium 沙箱
   或 GPU，则自动改用兼容模式（--no-sandbox --disable-gpu）重启一次。
   首次启动可能因此多等 1～3 秒，这是正常的。

4. 数据目录：
   - 正常情况：我的文档\个人技能树
   - 如果系统不允许写“我的文档”，会自动放到：
     本目录\我的技能树
   以应用内“设置 → 数据”显示的路径为准，那里也可以更换目录。

5. 界面缓存 / 窗口状态：
   本目录\.skilltree-userdata
   （不是 %APPDATA%，所以找不到是正常的。）
   删除它只会重置界面，不会动技能树数据。

6. 如果 Windows 提示“已保护你的电脑”：
   点“更多信息” → “仍要运行”。

7. 如果杀毒软件拦截：
   把整个 SkillTree 目录加入信任区（白名单）。

8. 如果仍然没有窗口：
   - 任务管理器里看有没有 SkillTree-app.exe；
   - 打开命令提示符，进入本目录执行：
     .\SkillTree-app.exe --no-sandbox --disable-gpu
     看它输出的错误；
   - 确认系统是 Windows 10/11 x64；
   - 启动器基于 .NET Framework 4.8（Windows 10/11 自带）。

9. 卸载/删除安装目录前，如果数据落在“本目录\我的技能树”，请先把它备份到别处。
